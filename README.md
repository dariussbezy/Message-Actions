# Message Actions

Reorder, hide or remove the buttons shown when you long-press a message.

Long-press a message once so its buttons are listed in the settings. Move them with the arrows, switch them off, remove them with the trash button and split the menu into boxes with section breaks. Removed buttons can be put back from the settings. The quick reactions row can be hidden too.

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

This repository holds the source and test builds of Message Actions. All plugins are published together in [dariussbezy's Plugins](https://github.com/dariussbezy/dariussbezy-Plugins).
